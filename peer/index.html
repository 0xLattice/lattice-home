LATTICE BROWSER PEER

A peer in this tab

This page runs Ivy, the network's peer-to-peer layer, in your browser, and connects to a node as a peer. Nothing here asks a server what the chain is. Each block arrives as bytes with the proof of work that secures it, and this tab checks both before it shows the block: the bytes hash to the block's ID, and the mined proof reaches the block and meets its target.

It checks work, not validity: it does not run transactions.
