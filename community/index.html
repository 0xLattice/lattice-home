Build software

Lattice is split into focused repositories. Start with the component you want to change.

Node

Consensus host, networking, storage, RPC, the mining coordinator, and a CPU worker.

Wallet

Local key custody, transfers, and cross-chain transaction handoff.

Site & explorer

Public website, network status, chain explorer, and community hub.

SDK

Shared clients, transaction encoding, relay, and verification libraries.

GPU miner

CUDA, OpenCL and Metal proof-of-work worker for the mining coordinator.

Consensus

Hierarchical GHOST, chain primitives, validation, and proofs.

Talk where the work happens

GitHub Discussions is the community forum for questions, ideas, operator help, and proposals. Decisions that affect the protocol belong in durable public threads, close to the code and specifications.

Open Discussions · Report a problem

For day-to-day conversation, join the Lattice Discord. Say hello in #general or talk about the chain in #nexus-blockchain. Use the links on lattice.build to find official accounts.

For public updates, follow @0xLattice on X. Bring questions and ideas back to Discord or GitHub Discussions.

You don’t have to write code to help.

Explain something you just learned. Try a guide and tell us where you got stuck. Share a chain idea and the problem it would solve. Welcome someone new and point them toward a useful resource.

For technical questions, include what you tried and what happened. For ideas, start with who they help. That gives other people a practical way to contribute.

Contribute safely

Contributions are welcome from pseudonymous and identified participants alike. Keep technical claims reproducible, disclose security problems privately, and treat other contributors with respect.
