Get started on Mac

  1. Download and unzip. Save the ZIP and double-click it in Finder to extract Lattice.
  2. Move to Applications. Drag Lattice into your Applications folder.
  3. Open Lattice. Open it from Applications. If macOS shows an unverified-developer warning, review “Opening on macOS” below.
  4. Set up your wallet. Follow the app’s prompts to create or import a wallet. Keep your recovery phrase private and store a backup. The app shows sync progress; allow it to catch up before using the wallet.

You can manage the node in the app’s Node screen. Use Node → Mining only if you choose to mine.

Opening on macOS

Continue only if you trust the source and have checked the download. For an unverified-developer warning or an alert that Apple cannot check the app:

  1. Try opening Lattice from Applications once, then dismiss the warning.
  2. Open System Settings → Privacy & Security. Scroll to Security and find the message about Lattice.
  3. Choose Open Anyway for Lattice, authenticate if asked, and confirm Open.

This creates an exception for this app. If Open Anyway is unavailable, check Apple’s opening-app guidance or your Mac administrator.

Stop if macOS reports malware, says the app will damage your computer, or says it is damaged. Do not override those warnings.

Verify the Mac download (advanced)

Checksums, the project signature, and the public key will be linked here when the release is available.

  • SHA256 checksums
  • Project signature for the checksums
  • Project public key

Compare the ZIP’s SHA256 with its entry in the release’s SHA256SUMS file. In Terminal, type shasum -a 256 (including a trailing space), drag the ZIP into Terminal, then press Return.

To authenticate the checksum file, use Minisign with the project’s public key. Confirm the key against a previously trusted copy or a separately trusted project source. Save the signature beside SHA256SUMS as SHA256SUMS.minisig, and the public key as lattice-releases.pub, then run this in that folder:

minisign -Vm SHA256SUMS -p lattice-releases.pub

A matching checksum shows that your ZIP matches the listed bytes. A valid project signature authenticates the checksums only to the key you trust. Neither is Apple notarization or a guarantee that the software is safe. If either check fails, do not open the app.

Download for Linux — .deb
Before installing on Linux

Linux packages are built for amd64 (x86-64) as .deb and AppImage files. Check your distribution and architecture in your system’s About settings. Both need glibc 2.35 or later. The .deb declares WebKitGTK 4.1, GTK 3 and SQLite dependencies; the AppImage bundles those libraries.

  1. Choose a package when available. Use the .deb on a compatible Debian or Ubuntu system. The AppImage is a separate option; review its requirements below.
  2. Install or open. Open the .deb with your system’s package installer and review its dependency prompts.
  3. Open Lattice and set up your wallet. Follow the app’s create or import prompts and back up your recovery phrase. The node starts syncing when the app opens; mining is optional.

If a dependency is missing or your system blocks the app, stop and check the platform requirements. The installed .deb has passed startup and UI checks.

Download for Linux — AppImage

The AppImage bundles WebKitGTK 4.1, GTK 3 and SQLite. In your file manager’s Properties → Permissions, allow the verified AppImage to run as a program, then open it. Labels vary by desktop.

Normal opening needs working FUSE mounting and helper access. This build does not require the libfuse2 package. FUSE mounting has not been tested; the extracted AppImage UI has been tested.

If mounting is unavailable, extraction is an alternative. In a terminal in the download folder, after verifying the file:

chmod +x Lattice_0.1.0_amd64.AppImage
./Lattice_0.1.0_amd64.AppImage --appimage-extract
./squashfs-root/AppRun

Extraction creates a squashfs-root folder. Keep it to run AppRun again.

Windows

Version 0.1.0 · x64 · WebView2 and an initialized default WSL distribution

The download is not available yet.

Download for Windows

The Windows installer is not signed with Authenticode. Windows may show an unknown-publisher or SmartScreen warning. A project signature does not establish Windows publisher trust; do not disable Windows security protections.

Before installing on Windows

The Windows app runs its node in Windows Subsystem for Linux (WSL). It uses your default Linux distribution, which needs glibc 2.35 or later and SQLite; the repository lists Ubuntu 22.04 or later and Debian 12 or later.

  1. Prepare WSL. Follow Microsoft’s WSL setup instructions. This may require administrator access and a restart. Open your default Linux distribution once to finish its setup, and ensure it meets the glibc and SQLite requirements above.
  2. Check WebView2. The app also requires Microsoft’s WebView2 Runtime. The installer downloads WebView2 if it is missing, so an internet connection is needed for that step. You must set up WSL and its default distribution separately.
  3. Install when available. Download the verified x64 .exe installer, open it, and follow the setup prompts. It is an NSIS installer. Read any Windows security warnings before deciding whether to proceed.
  4. Open Lattice and set up your wallet. Follow the create or import prompts and back up your recovery phrase. The app starts its node in your default WSL distribution and shows sync progress. Mining is optional.

Microsoft’s WSL setup recipe requires Windows 10 version 2004 (build 19041) or later, or Windows 11. That is a WSL prerequisite, not a tested Lattice desktop support matrix. Compatibility checks used Windows Server 2025; desktop Windows versions do not yet have a formal test matrix. A malware alert is a reason to stop, not to bypass a protection.
